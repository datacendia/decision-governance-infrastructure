## 5. Contribution Levels

| Level | Description | Time Commitment |
|-------|------------|:--------------:|
| **Endorser** | Public statement supporting DGI standardization | Minimal |
| **Reviewer** | Review and comment on DGI specification drafts | 2–4 hours/quarter |
| **Working Group Member** | Active participation in ISO working group meetings | 4–8 hours/month |
| **Editor / Co-Author** | Contribute to specific sections of the specification | 8–16 hours/month |
| **National Body Delegate** | Represent a P-member national body in SC 42 | Per national body requirements |

## 6. How to Contribute

### Option A: GitHub

1. Fork this repository
2. Open an issue titled `Contributor: [Your Name] — [Country]`
3. Include the contributor profile (template below)

### Option B: Email

Send your contributor profile to: **contributors@datacendia.com**

### Contributor Profile Template

```yaml
name: "[Full Name]"
affiliation: "[Organization]"
country: "[Country]"
role: "[Academic / Regulator / Practitioner / Standards Body / Legal / Other]"
expertise:
  - "[Domain 1]"
  - "[Domain 2]"
relevant_standards_work:
  - "[ISO/IEC committee participation, if any]"
  - "[Other standards contributions]"

  - "[Relevant publication, if any]"
```
